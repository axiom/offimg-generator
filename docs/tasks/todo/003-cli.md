# 003 — Command-line interface

Depends on: 002.

## Goal

Convert one image without opening a desktop window.

## Scope

Add the `offimg` binary using clap. Start with
`offimg convert INPUT OUTPUT --fit fit|crop --dither threshold` and the shared
core settings. Extend algorithm and adjustment flags in task 004. Make GUI
dependencies optional when they are introduced. Document runnable examples.

## Acceptance

- [ ] `--help` explains arguments and defaults.
- [ ] A CLI integration test converts a fixture and validates its BMP output.
- [ ] Invalid input/options and write failures produce nonzero exit codes.
- [ ] Existing output is preserved unless `--force` is supplied.
- [ ] Input/output identity is rejected, including aliases where detectable.
- [ ] The CLI builds and runs without GUI dependencies or a display server.

## Progress / handoff
