# 003 — Command-line interface

Depends on: 002.

## Goal

Convert one image without opening a desktop window.

## Scope

Add the `offimg` binary using clap. Start with
`offimg convert INPUT OUTPUT --fit fit|crop --dither threshold` and the shared
core settings. Extend algorithm and adjustment flags in task 004. Make GUI
dependencies optional when they are introduced. Document runnable examples.

## Acceptance

- [x] `--help` explains arguments and defaults.
- [x] A CLI integration test converts a fixture and validates its BMP output.
- [x] Invalid input/options and write failures produce nonzero exit codes.
- [x] Existing output is preserved unless `--force` is supplied.
- [x] Input/output identity is rejected, including aliases where detectable.
- [x] The CLI builds and runs without GUI dependencies or a display server.

## Progress / handoff

Added clap-based `offimg convert INPUT OUTPUT --fit fit|crop --dither threshold`
and `--force`, with shared core enum parsing and documented examples.
`export::save` uses a same-directory tempfile, sync, and atomic persist (no-clobber
unless overwrite is authorized). Device/inode comparison protects input identity,
including hardlinks and symlinks. All processing finishes before output creation.

Verified `nix develop --command cargo test` (14 integration tests), formatting,
and all-target/all-feature Clippy with warnings denied. CLI integration tests
remove DISPLAY/WAYLAND_DISPLAY, convert a supplied fixture pixel-for-pixel,
check help/errors, reject path aliases, and exercise failed-export cleanup and
preservation of existing output. No GUI dependencies are present.
